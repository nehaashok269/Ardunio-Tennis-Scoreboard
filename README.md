# Ardunio-Tennis-Scoreboard
ACEBOARD - is a portable electronic scoreboard for tennis. 
Author: Neha Ashok 

This GitHub repo contains a pdf and Arduino code implementation.  

1. The pdf (AceBoard_Tennis_Portable_Electronic_Scoreboard.pdf) documents the problem statement and my journey through prototyping, design, and implementation. 

2. Arduino code implementation can be found in 2 separate files
  a. Arduino_code_breadboard_tiebreak_pushbutton.txt - Arduino code for breadboard with push buttons
  b. Arduino_code_Tiebreak_IR_Transmitter.txt - Arduino code for finished product with IR transmitter-receiver
