# Ardunio-Tennis-Scoreboard
ACEBOARD - is a portable electronic scoreboard for tennis. 
This GitHub repo contains a pdf and Arduino code for breadboard with push buttons and Arduino code for finished product with IR transmitter-receiver
Author: Neha Ashok 

1. The pdf (AceBoard_Tennis_Portable_Electronic_Scoreboard.pdf) documents the problem statement and my journey through prototyping, design, and implementation. 

2. Arduino code implementation can be found in 2 separate files - Tiebreak_IR_Transmitter.txt and Bradboard_tiebreak_pushbutton.text
